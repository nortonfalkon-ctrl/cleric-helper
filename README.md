# Cleric-helper

A small Foundry VTT v13 / dnd5e helper module for Life Domain Cleric healing.

## v0.1.8

- Adds Disciple of Life directly before dnd5e builds a healing DamageRoll.
- Uses `2 + spell slot level`.
- Includes a repair pass for invalid numeric `healing.bonus` values left by earlier test versions.
- Does not handle Blessed Healer yet.
